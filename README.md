# Программа мониторинга роботов.

---

`Данный API позволяет:`
-

- # Увидеть список всех роботов
- # Найти робота по ID
- # Найти робота по статусу
- # Увидеть всех роботов
- # При ошибке получить нужный код ошибки

---
---

> # Как установить? 
>> 1. Скачайте к себе main.py
>> 2. Зайдите в 1 директорию с ним
>> 3. Введите `py -m uvicorn main:app --reload`
>> 4. Перейдите по адресу `http://127.0.0.1:8000`
>> 5. Готово, тестируйте!
